## 🌟 Overview
**DreamGame AI** allows anyone to describe any game they envision and immediately play it in the browser. Powered by **Pollinations AI**, it uses code generation models to craft physics loops, collision systems, keyboard/touch bindings, and canvas rendering dynamically.

## 🔑 Bring Your Own Pollen (`<polli-connect>`)
- Implements the official Pollinations `<polli-connect>` drop-in component.
- Authorizes spend from the visitor's own Pollen wallet (`app-key="pk_DJzonDcZRXo3452Q"`).
- Zero server backend required; completely client-side and open-source.

## 🕹️ Features
- **Prompt to Playable Game:** Describe any genre (Platformer, Space Defender, Dungeon Slasher, Maze Runner).
- **Physics & Gameplay Engine:** Standalone 60 FPS HTML5 Canvas game loops with score, lives, and game over loops.
- **Source Code Inspection:** View and inspect the synthesized JavaScript/HTML code directly.
- **Instant Restart & Customization:** Test different game mechanics with zero latency.
